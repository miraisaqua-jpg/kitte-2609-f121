# 切手いくら？

封筒の種類と A4 の枚数・クリアファイル数・返信用封筒から、郵便料金と切手の貼り方を出すスマホ向けツール。
`index.html` 1ファイルで動きます（サーバー不要）。

## 使い方
- 封筒を選ぶ（長3 / 長4 / 洋長3 / 角2 / 角3）
- A4 の枚数、クリアファイル数、返信用封筒を入れる
- 料金と切手の組み合わせ（最少枚数 / 110円ベース / 手持ち在庫）が出る
- 「詳細」でホッチキス・付箋・紙の厚さ・速達・書留を指定できる
- 右上「在庫」で持っている切手を登録、「設定」で実測した重さに補正できる

## スマホで見る
1. `./deploy.sh` を実行（初回のみ先に `gh auth login -h github.com -p https -w`）
2. 表示された URL を iPhone の Safari で開き、共有 → ホーム画面に追加

公開先は GitHub Pages（検索エンジンには載せない設定）。設計書と学習用文書は .gitignore で公開対象から外しています。

GitHub を使わない場合は `index.html` を AirDrop で iPhone に送り、「ファイル」アプリから開いても動きます。

## 料金改定のとき
`index.html` 内の `RATES` ブロック（`料金マスタ` の見出し）だけ直して `./deploy.sh`。

## 重さの既定値
A4 普通紙 4.2g、長3 6g、長4 4g、洋長3 6g、角2 15g、角3 12g、クリアファイル 25g。
アプリの「設定」から実測値で上書きできます（端末に保存）。
